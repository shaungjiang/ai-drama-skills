# 3D仙侠风格方向

国漫预设按用户参考的半写实仙侠CG审美调整。重点是精致自然的东方五官、柔和骨相过渡、细腻皮肤与眼部细节、有体积和散丝的长发、可辨的织物与金属饰件，以及柔和面部塑形光配暗背景。

背景暖金光点只作为少量景深层次；法术光效由剧情需要决定。参考风格不等于批准某张定妆图，不要求逐镜复制同一构图，也不改变已锁定角色的身份锚点。画面不包含平台UI、字幕、账号信息或参考视频具体文字。

修改preset后，对已有项目使用 `style set cinematic_3d_donghua --confirm` 更新锁定风格，重新storyboard生成提示词。旧图片有不同来源哈希，应保留为历史预览而非自动验收。先用一张角色定妆确认方向，再决定完整批量的生产资产。

这一规则是美术约束；实际是否达到参考质感必须查看生成图片。普通文生图仍不具备跨镜头身份参考能力。
