# 豆包视频提示词

## 触发场景

把分镜和已生成图片导出为H3结构化与自然语言豆包视频提示词、镜头时长和素材核对表；视频由用户手动生成。

## 输入要求

用户制作目标、项目路径、原文或Episode JSON，以及对应的已有角色图/场景/工作流。具体读取 [共享工具说明](references/shared_tools.md)。

## 工作步骤

1. 根据所选模式确认单首帧或双帧输入能力；不假定所有豆包模式支持双帧。
2. 每镜明确主体、开始状态、人物动作、表情、衣发与环境运动、摄影机、光影、节奏、结束状态和一致性约束。
3. 精细动作减少摄影机运动；不堆叠冲突动作，不新增人物，不让道具凭空消失。
4. doubao export 输出两份提示词和逐镜核对表；命令只写文本与素材ZIP，不调用视频API。
5. 正式素材包要求 qc PASS；缺图或未验收用 --draft 并清楚标明。

## 输出格式

共享 CLI 产生的JSON、Markdown与真实PNG及状态；报告实际路径、审批状态、测试范围和缺失能力。创作数据遵守项目 `templates/episode.schema.json` 与 `templates/image_prompt.schema.json`。

## 使用的工具

优先已安装的 `ai-drama` 或项目 `scripts/ai-drama.ps1`；执行逻辑统一使用 `src/ai_drama`。需要视觉确认时读取实际图片。

## 错误处理

缺输入先读取已有项目；真正影响结果的缺项再询问。环境离线可处理剧本与导出，不能声称真实出图。模型节点缺失报告能力，不擅自下载、安装、升级。未审批角色停在候选状态。任务超时按记录恢复，原素材与原工作流另存保留。

## 使用示例

用户：输出这一集所有镜头的H3和可复制豆包提示词，我自己生成视频

```powershell
.\scripts\ai-drama.ps1 doubao export --mode single --package --draft
```
